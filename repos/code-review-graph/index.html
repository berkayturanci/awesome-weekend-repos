A local code graph that gives AI agents only the files that changed

★ 30.5kMIT license

Stop making your AI agent re-read your whole codebase

One command maps your whole codebase.

code-review-graph uses Tree-sitter to parse your repo into a code graph — functions, classes, callers, tests — and stores it locally in SQLite. No cloud, nothing leaves your machine.

Tree-sitter AST graph · local SQLite · no network calls

AI reviews read only what changed.

When you change a function, code-review-graph traces its blast radius — every caller, every test, everything actually affected — and hands your AI agent just that.

blast-radius analysis · incremental updates under 2s

82 times less context, per question.

Ask it something like "how does auth work," and across six benchmarked repos, the graph answers with a median of eighty two times less context than dumping the whole codebase in.

median ~82x vs. whole-codebase reads · 6-repo benchmark

30 MCP tools. Works with your agent.

It ships thirty MCP tools and plugs straight into Claude Code, Cursor, Codex, Windsurf, Copilot, and more — plus a GitHub Action that risk-scores every pull request.
