Run your own GitHub on a $5 server.

Gitea packs an entire Git forge into one single binary.

First, Gitea is written in Go and compiles into a single binary. Drop it on a $5 cloud server or a Raspberry Pi and start working.

single Go binary · runs on Linux, macOS, Windows & ARM

Full pull requests, issues, and code review out of the box.

Second, you get the complete developer experience: side-by-side diffs, branch protection rules, issue milestones, and collaborative team reviews.

complete workflow: pull requests, milestones & review tools

Run native GitHub Actions workflows with built-in Gitea Actions.

Third, Gitea Actions uses the Act runner engine and understands standard GitHub Actions YAML syntax, so your continuous integration runs locally for free.

Gitea Actions: uses GitHub Actions workflow syntax

Gitea uses a fraction of the memory that GitLab demands.

Fourth, while GitLab demands at least 4GB of RAM to boot, Gitea comfortably serves dozens of developers on under 100MB.

RAM usage: Gitea ~90MB vs GitLab 4GB+ minimum requirement
