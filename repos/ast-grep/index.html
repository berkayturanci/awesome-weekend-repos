Stop using regex to refactor your code.

Regex fails when code spans multiple lines or variable names overlap.

First, regex treats your codebase like flat text. It breaks on multiline formatting, matches identifiers inside comments, and turns automated refactoring into a disaster.

regex matches text strings · blind to AST syntax & scopes

Search code using actual code syntax and metavariables.

Second, ast-grep uses Tree-sitter to parse your code into syntax trees. You write patterns using actual language syntax and dollar variables to match expressions, statements, and arguments across twenty languages.

Tree-sitter AST parsing · supports 20+ languages natively

Perform safe codebase-wide rewrites directly from the command line.

Third, its sg rewrite command lets you refactor code across thousands of files. It extracts matched subtrees, preserves surrounding indentation, and shows interactive diffs before applying any changes.

sg rewrite · interactive diffs · preserves code formatting

Define custom CI lint rules in three lines of clean YAML.

Fourth, you can turn any search pattern into an automated CI lint rule. No complex ESLint plugin boilerplate, no compiler APIs, just clean YAML rules enforced at blazingly fast Rust speed.

sg scan · custom YAML lint rules · no plugin boilerplate
