Stop fighting your AI agent for browser tabs

Same browser. Two parallel spaces.

Existing automation frameworks spin up a separate browser. Logins don't carry over, and you end up fighting the agent for control of the tabs.

standard browser vs parallel spaces

Add the skill. Run the agent.

To use it, just add the ego-browser skill to your agent's directory, or let it install the app. Then, instruct it in plain language.

npx skills add citrolabs/ego-lite

Your logins and session carry over.

On first launch, you can import your Chrome profile. The agent gets instant access to your sessions and cookies without manual authentication.
