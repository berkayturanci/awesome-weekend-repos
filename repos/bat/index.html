See your files the way your editor does

Same command. Readable output.

It's the official tagline: a cat clone with wings. Same one-word command, but the output comes back highlighted for a huge list of languages, with line numbers.

syntax highlighting — a large number of languages

It shows what you changed, inline.

bat talks to git. Modified lines get marked right in the left margin — you see your uncommitted changes while you're reading the file, not after a diff.

git gutter — modifications vs. the index

Pipe it — it behaves like cat.

The part that makes it safe: pipe it into anything and it detects the non-interactive terminal, drops the decorations, and acts as a drop-in cat replacement. Scripts never notice.

piped → plain output · alias cat='bat --paging=never'
