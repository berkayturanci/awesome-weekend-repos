Stop downloading 200MB Electron apps for simple sites.

One CLI command packages any URL into a standalone binary.

You run pake with any web address, and in seconds it compiles a standalone native application. No complex build toolchain required.

single CLI command · zero complex configuration

Electron ships a whole browser. Pake uses your system webview.

Electron bundles an entire copy of Chromium and Node.js with every single app. Pake uses Tauri under the hood, hooking directly into your operating system's native webview.

Tauri core · utilizes native macOS WebKit / Windows WebView2

Pake desktop apps launch instantly and consume minimal RAM.

Because it skips Chromium overhead, memory consumption drops from hundreds of megabytes down to negligible background levels.

official showcase · runs Twitter, YouTube, and ChatGPT

The resulting binaries are up to twenty times smaller than Electron.

Your resulting binary is roughly three megabytes instead of two hundred. It supports custom shortcuts, window transparent effects, and tray icons out of the box.

20x smaller binaries · native shortcuts & system tray
