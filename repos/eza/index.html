eza-community/eza

Upgrade the 40-year-old ls command with Git status and tree views

★ 23.2kEUPL-1.2 license

The ls command has not changed in 40 years.

eza replaces standard ls with rich colors and icons.

First, eza brings modern color-coding, human-readable file metadata, and built-in Nerd Font icons to standard directory listings.

color-coded permissions, sizes, and file type icons

View real-time Git status directly inside directory listings.

Second, with the git flag enabled, eza shows modified, staged, and untracked statuses next to every single file and folder.

inline git tracking: modified, staged, and untracked states

Recurse into nested directories with interactive tree view.

Third, forget installing a separate tree utility. Just pass the tree flag with a level limit to inspect nested hierarchies cleanly.

integrated tree hierarchy view replaces separate tree tool

Native support for extended attributes and clickable hyperlinks.

Fourth, eza parses Unix extended attributes, security contexts, and emits clickable terminal hyperlinks straight to your file manager.

extended attributes, octal permissions, and OSC8 hyperlinks

Over 21,000 developers switched to eza on GitHub.

Built in Rust as the community continuation of exa, it is blazing fast, open-source under EUPL, with over twenty-one thousand stars.
