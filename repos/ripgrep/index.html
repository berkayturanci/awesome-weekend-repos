BurntSushi/ripgrep

A code search tool that skips the junk and just finishes

★ 66kRustMIT / Unlicense license

Search the whole Linux kernel in 0.08 seconds

It just finishes.

Point it at a codebase and it's done before you blink. The project's own benchmark: five hundred thirty-six matches across the Linux kernel in 0.082 seconds — git grep took thirty-two times longer.

README benchmark: 0.082s vs git grep 2.670s

It skips what you'd never read anyway.

Here's the trick: by default it respects your gitignore, skips hidden files, skips binaries. It's not just faster at searching — it searches less, and only the part you actually care about.

.gitignore · hidden · binary skipped — rg -uuu disables

Search only the files that matter.

Need just Python? rg dash t py. Everything except JavaScript? Dash capital T js. Type filters are built in — no find-pipe-grep gymnastics.

rg -tpy foo · rg -Tjs foo — include or exclude file types

All of grep's tricks, none of the wait.

And you give nothing up. Unicode is always on and still fast. It searches inside gzip and zstd archives, does replacements, and can switch to PCRE2 when you need look-arounds.

Unicode always-on · -z compressed search · PCRE2 optional
