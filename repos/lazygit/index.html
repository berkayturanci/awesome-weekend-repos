A keyboard-driven UI for git, right inside your terminal.

Git without memorizing a single command.

The git commands you re-google every week.

Staging a line, reordering commits, undoing a bad rebase: each needs a flag you half-remember.

the flags: git add -p · rebase -i · reflog

One command opens the whole UI.

Install once with brew install lazygit, then type lazygit. Files, branches, commits, stashes, all keyboard-driven.

brew install lazygit · run: lazygit

Stage a single line with the spacebar.

Press space to stage one line, a for the whole hunk. No git add -p, no interactive prompts.

space = stage line · a = stage a hunk

Reorder and squash commits by keystroke.

Press i to rebase, then squash with s, drop with d, reorder with ctrl-j. Botch it? z undoes it.

i rebase · s squash · d drop · z undo

80.6k stars. Written in Go. MIT.

Eighty thousand stars, Go, MIT, one binary. What you memorized is now a keystroke.
