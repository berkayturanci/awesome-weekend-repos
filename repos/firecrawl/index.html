firecrawl

Turn any website into clean LLM-ready markdown.

★ 20kTypeScript

Stop writing custom web scrapers for LLMs.

AI needs markdown, not messy HTML.

When you feed web pages to LLMs, raw HTML wastes tokens and breaks prompts. Firecrawl cleans the page, removing ads, trackers, and style noise instantly.

Raw HTML wastes LLM tokens; markdown is clean and structured

Run Firecrawl with one command.

You can run Firecrawl locally on your machine with one Docker command. It spins up a local API ready to scrape and crawl.

docker run -p 3002:3002 firecrawl/firecrawl

Scrape any page with a simple API call.

Send a POST request to scrape a single page. It handles JavaScript-heavy sites, proxies, and rate limits out of the box.

Handles dynamic JS and proxies automatically

Define schema to extract structured JSON.

You can pass a Zod schema to extract exactly the fields you need, like pricing tables, article authors, or product details as clean JSON.

Extract structured data using custom schemas
